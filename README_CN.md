# Gate

[English](README.md) | [中文](README_CN.md)

Gate 是监控多台 SSH 服务器上编程工具会话的简单面板，支持 **Codex** 和 **Google Antigravity CLI（agy）**。
查看需要关注的会话、打开对话，在浏览器中继续工作。

![侧边栏与对话](assets/session-monitor.png)

## 工作方式

每条连接选择工具和 SSH 账户。会话、历史和执行由工具管理，Gate 提供面板、聊天、审批和中断操作。
没有 Gate 远端运行时、任务编排、hook 观察器、会话文件扫描或逐轮启动 CLI。

| 工具 | 连接方式 | 会话行为 |
| --- | --- | --- |
| Codex | 通过 SSH Unix socket 转发连接原生共享后台 | 与终端共享实时会话，关闭 Gate 不会停止 Codex。 |
| Antigravity（agy） | 通过 SSH 保持一个 `agy acp` 进程 | 列出、加载原生会话；实时状态和审批覆盖此连接发起的工作。断开可能中断这些工作，其他终端进程不受影响。 |

agy 的 ACP 不提供其他终端客户端的实时状态，也不支持会话重命名或运行中追加消息。
Saved 表示历史会话，不代表终端当前空闲；同一会话请避免在两个客户端同时发送。
界面按能力显示控件，agy 需等当前轮次结束或先中断，再发送下一条。

Gate 通过统一后端接口路由操作。工具适配器负责原生协议，SSH 访问、仓库分组和界面独立于具体工具。

## 开始使用

1. 在运行 Gate 的机器上安装 Node.js 20+。
2. 在 SSH 服务器安装所选工具并登录：
   - 支持 `codex app-server daemon` 的 Codex CLI（已验证 0.171.0）。
   - [支持 ACP 的 Antigravity CLI](https://antigravity.google/docs/ide/extensions/acp/)（已验证 agy 1.5.16）。
     尚未登录时，在该服务器执行 `agy acp --login`。
3. 运行：

   ```bash
   npm i -g @marukohe/gate
   gate
   ```

4. 打开 `http://localhost:3030`，点击 **Add server**。优先从 **SSH host** 选择运行 Gate 的机器上
   `~/.ssh/config` 已有的主机，也可选择 **Enter manually…** 手动填写，然后选择 **Tool** 并保存。
   导入会填入名称、地址、端口、用户名和首个可用密钥路径。展开连接摘要可修改这些字段或切换密码认证，密码需单独输入。
   如果登录 PATH 中找不到工具，在 **Tool executable** 填写绝对路径。
   同一台机器同时使用 Codex 和 agy 时添加各自的工具连接，侧边栏会合并为一个服务器分组；已有 Codex 配置会自动迁移。

导入需要 Gate 所在机器安装 OpenSSH。主机列表包含 `Include` 文件里的明确 `Host` 别名，通过 `ssh -G` 解析配置。
保存的是可编辑的连接配置副本，不会修改 `~/.ssh/config`，也不自动跟随该文件之后的变化。
依赖 ProxyJump、ProxyCommand 或证书的配置不能直接导入，需手动填写可直连的服务器。
导入字段使用 Gate 原有的密钥／密码 SSH 连接方式，不代表支持全部 OpenSSH 选项。

Codex 连接原生共享后台；后台尚未运行时会启动它，已有后台不会被重启。
SSH 服务器需要允许 Unix socket 转发，无需公开 Codex 网络端口。
使用与终端相同的远端系统用户和 Codex 配置。

## 日常使用

- **侧边栏**：服务器列表、搜索、状态筛选、新建会话和连接设置集中在可折叠侧边栏，右侧直接显示对话。
  当前会话高亮，会话行只显示状态点、名称和工具标签。左上角按钮收起或展开，桌面端记住收起偏好。
  手机端列表占满页面，选择会话后自动收起。切换会话保留搜索、筛选和仓库展开状态。
- **监控**：侧边栏按服务器、仓库归类会话，同仓库的 worktree 合并。
  同一 SSH 地址和端口上的工具共用一个服务器分组，同仓库会话混排，标题旁用工具标签区分：Codex 为绿色，Antigravity 为紫色，适配浅色和深色主题。
  **Servers** 统计服务器数量，不再按工具重复计数。
  需要回应的项目优先显示，有活跃会话或当前会话的仓库默认展开，其他仓库默认收起。
  展开后显示所有工具的未屏蔽、未归档会话，包括空闲和已保存会话；点击仓库标题展开或收起整个列表。
  搜索直接显示匹配结果。完整路径悬停查看，
  只有重名项目才显示简短父目录。非 Git 目录按工作目录分组。
- **快捷筛选**：点击 **Running** 或 **Needs you**，只展示对应状态的会话并自动展开，仍按服务器和仓库分组。
  再次点击同一筛选恢复全部；切换会话时保留筛选。结果随会话状态自动更新。
- **对话布局**：顶部只有一条紧凑工具栏，包含收起后的侧边栏入口、会话名称和状态数量。手机端状态按钮显示图标与数量，为名称留出空间。
  点击名称可查看服务器、目录、完整状态，以及重命名、主题和打开会话列表操作。
- **会话状态**：对话页顶部的 **Running** 包含当前会话，列表中标为 **Current**；**Needs you** 显示其他待处理会话。
  点击数量可查看并切换。
  其他会话新进入等待或原生报错状态时会短暂提醒，显示服务器和原因；打开或关闭提醒后，待处理项仍保留至状态变化。
  切换后，顶部左箭头返回原会话，右箭头处理下一个待回应会话。
  草稿、模型、强度和阅读位置在页面打开期间保留于浏览器内存，刷新后清空。
- **过滤**：点击服务器旁的过滤图标，在 **Available directories** 中搜索目录并点击 **Hide**。
  服务器有多个工具时，在弹窗的 **Tool** 中选择要配置的工具，原有过滤和归档记录各自保留。
  **Blocked directories** 默认折叠，需要恢复时展开并点击 **Show**。也可在 **Add another directory** 中输入父目录，保存后屏蔽其现有及未来子目录，
  按会话实际工作路径匹配。
- **归档**：点击会话行的归档图标，在 Gate 中隐藏会话；在 **Session filters → Archived sessions** 中可恢复。
  过滤和归档只影响这个 Gate 的显示，会话继续运行。
- **继续**：打开会话查看历史并发消息。Codex 还支持在当前轮次运行时补充指令。
  向上滚动接近顶部时自动加载更早消息，并保持阅读位置；也可用 **Earlier messages** 手动加载。
  加载失败后点击该按钮重试，滚动不会反复重试失败请求。
  向上滚动会暂停自动跟随，向下回到接近底部时恢复跟随新输出。
  加载历史时保持现有内容与控件稳定；后台刷新不会覆盖请求期间收到的新输出。
- **发送图片**：点击输入框旁的图片按钮，或将图片拖入输入区域。复制图片或截图后，在会话页面按 **Ctrl+V**
  （macOS 为 **⌘V**）即可添加附件，不必先点输入框。粘贴后显示预览并聚焦输入框，方便补充说明，不会自动发送。
  发送前可查看缩略图、移除附件，也可只发图片。支持 PNG、JPEG、WebP 和 GIF，每条最多 4 张，单张 5 MB、合计 10 MB。
  未发送附件在当前标签页切换会话时保留，刷新网页后清除；已发送图片可点击放大。Codex 从原生历史恢复图片；
  agy 1.5.16 能接收图片，但重放历史时不返回附件，因此工具连接重建后图片不再显示。
  执行 `!` shell 命令前需要移除附件。
- **文件与图片**：消息里的本地 Markdown 链接会在新标签页打开会话所在服务器的文件，支持 `main.ts:42`、`main.ts#L42` 行号跳转。
  相对路径按会话工作目录解析，本地图片直接显示。通过现有 SSH 连接的 SFTP 读取，每个文件最多 10 MB；1 MB 内的文本可预览，其余文件下载。
- **文件侧边栏**：点击对话右上角的面板图标，从当前会话的工作目录浏览服务器文件。支持打开文件夹、返回上级或工作目录、输入路径和刷新，
  每个目录最多显示 1,000 项。点击文件可只读预览文本或图片，也可在新标签页打开或下载。
  文本显示原文件行号，文件名旁的 **Wrap lines** 开关控制自动换行，并在当前浏览器记住偏好。
  文件栏跟随当前会话，各会话的浏览目录和文件保留在当前标签页内存中。窄窗口下暂时收起左侧会话列表，手机端全屏显示文件；
  关闭后回到对话，保留草稿和阅读位置。两种工具均通过 SFTP 浏览，不发送模型请求。
- **Shell 命令**：输入 `!pwd`、`!git status` 或其他 `!命令`，直接通过 SSH 在会话工作目录执行，不经过模型推理。
  结果显示标准输出、错误输出和退出码；切换会话仍会保留，刷新网页后清除，不写入模型上下文。
  每次使用独立的非交互 shell，最多等待 60 秒、保留 128,000 个输出字符；目录和环境变量的修改不延续到下一条命令。
- **模型与推理强度**：在输入框上方选择模型及其支持的推理强度，随下一条新轮次消息生效。
  模型、强度选项及默认值来自当前工具，发送后由工具保留为会话默认设置。
  运行中的轮次保持原设置，结束后可切换。
- **重命名（Codex）**：点击对话标题，再点击 **Rename**，修改名称并保存。名称保存在 Codex，与终端共用。
- **新建**：点击服务器旁的 **+**，有多个工具时先选择工具，再填写工作目录和第一条指令，创建该工具的原生会话。
  服务器的设置入口同样可选择要编辑的工具。
- **回应**：在对话中允许或拒绝工具请求的操作。Codex 还支持结构化问题；Gate 尚不支持的 Codex 请求仍会显示，可在其终端处理。
- **中断**：停止当前轮次，保持工具连接。

对于 Codex，Gate 通过所连接的共享后台操作会话，无法接管独立的 `codex --no-daemon` 进程。
连接异常时明确报错；未确认送达的消息不会自动重发。
状态与连接细节见 [Session 说明](docs/session-monitor.md)。

Gate 用于可信内网，不提供身份认证。
SSH 配置、目录过滤和 Gate 归档保存在 `~/.gate/gate.db`，密码不会返回浏览器。
显示配置在 Gate 重启后仍生效，所有访问此 Gate 的浏览器共用。
旧数据库中的 Gate 数据保留为不再使用的归档；当前会话历史由各工具保存。

```bash
gate --port 8080
gate --host 127.0.0.1
gate --data-dir /custom/path
```

## 开发

```bash
npm install
npm run dev           # 前端 :5173，后端 :3030
npm run build
npm test --workspace=server -- --run
npx playwright install chromium
npm run test:ui       # build first
```

前端：React、TypeScript、Vite、Tailwind。后端：Express、ssh2、ws，SQLite 保存连接配置和显示偏好。
